# Phase 17 — General Sentinel-2 Land-Cover Segmentation Model Review

**Research checked:** 2026-10-11
**Decision:** No publicly verifiable, locally deployable pretrained checkpoint was found that satisfies the existing single-scene, pixel-level general land-cover map requirement. Do not integrate a candidate or enable AI readiness on this evidence.

## Current application contract and constraints

- Copernicus acquisition currently saves Sentinel-2 L2A bands B02, B03, B04, and B08. The acquisition path does not expose the additional bands, temporal inputs, or preprocessing expected by several candidates below.
- The AI endpoint accepts one owner-scoped stored scene. Its existing scikit-learn adapter emits a class-index GeoTIFF and a per-pixel maximum-probability GeoTIFF; it is not an upstream pretrained segmentation model.
- The current environment has no PyTorch dependency. The configured limits include a 256 MiB model artifact ceiling, 10 million AI inference pixels, one concurrent analysis, and a 300-second analysis time limit. CPU/RAM latency has not been measured for a neural segmentation model.
- The model directory is private. Existing API authentication, scene ownership, job/result ownership, raster validation, and geospatial output handling are already part of the workflow and must remain in force for any later adapter.

### Evidence and uncertainty

- The official Satlas source distinguishes data/task labels from released pretrained backbones. The listed public fine-tuned Sentinel-2 artifacts are task-specific; no general land-cover head was found in the inspected model release. Its repository's `land_cover` task taxonomy is not proof that a corresponding trained checkpoint is publicly available.
- The official Prithvi model inventory and candidate model cards inspected did not include a general land-cover segmentation head. This is a bounded finding about the checked public releases, not a claim that no private or later checkpoint exists anywhere.
- The ESA WorldCover product's 11-class labels and CC-BY-4.0 statement are verified from the AWS Open Data Registry. Its output is a derived map, not an independently validated model checkpoint. Training and testing against the same product would measure agreement with that product, not independent scientific accuracy.
- No published artifact checksum was checked against a local weight file. No checkpoint or evaluation dataset was saved or installed in the project.

## Defensible next step

Do not relabel an encoder, hosted prediction layer, regression output, flood mask, or single-purpose segmentation model as a general land-cover classifier. The smallest defensible path is to train a new, compact per-pixel segmentation head against a versioned, licensed label source, with inputs aligned to the application's actual four-band Sentinel-2 L2A contract:

1. Use selected, cloud-masked B02/B03/B04/B08 L2A scenes and a fixed reflectance scaling/nodata policy. Keep the band order explicit. Tile spatially bounded AOIs and resample only after documenting grid/CRS alignment.
2. ESA WorldCover 2021's 11 classes can provide CC-BY-4.0 supervision where the acquisition year and geography are suitably aligned. Treat those masks as product labels/weak supervision; they may encode errors and class definitions from the source product.
3. Before training, identify and clear rights for a second, independent validation set. LandCoverNet's paper describes globally distributed 10 m Sentinel-2 examples and labels verified by three annotators, but its current authoritative distribution/license was not verified in this review; do not use it until its current terms are confirmed. Alternatively, commission or assemble AOI-scoped reference labels with documented permission.
4. Freeze a spatially blocked holdout by geography before tuning. Keep all chips, adjacent windows, repeat observations, and dates from a held-out site together to reduce spatial/temporal leakage. Do not use WorldCover tiles used for training as independent test ground truth.
5. Report label-source version/license, AOIs and dates, valid sample/pixel counts, per-class precision/recall/F1, confusion matrix, overall accuracy, per-class IoU and mean IoU, valid-pixel coverage, class imbalance, and uncertainty. Add boundary F1 only if boundaries are a declared target. Publish no metric until this evaluation runs.
6. Provision an operator-approved artifact outside source control, verify its trusted digest, benchmark CPU latency and peak memory at the actual tile size, and only then define a safe artifact-size limit and adapter. Keep readiness `model_not_ready` until those checks and real-scene geospatial tests pass.

No new neural dependency, adapter, model artifact, or dataset is justified by the current evidence. The existing inference route/UI and deterministic index tools should remain unchanged until a compatible model and license package are selected.
